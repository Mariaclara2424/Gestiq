# GestiQ - Sistema de Gestão Corporativa

O **GestiQ** é uma solução centralizada desenvolvida para otimizar o fluxo de trabalho corporativo. O sistema visa integrar a gestão de departamentos, projetos, tarefas e agenda em uma interface intuitiva, segura e escalável.

---

## 🚀 Funcionalidades Principais

* **Gestão de Projetos:** Criação, acompanhamento e organização de cronogramas.
* **Módulo de Tarefas:** Atribuição e controle de entregas por equipe.
* **Agenda Corporativa:** Organização de compromissos e prazos críticos.
* **Gestão de Departamentos:** Estruturação hierárquica e administrativa.
* **Navegação Fluida:** Painel de controle centralizado para acesso rápido às informações.

## 🛠️ Tecnologias Utilizadas

O GestiQ foi construído com tecnologias focadas em performance e manutenibilidade:

* **Backend:** PHP (Arquitetura MVC).
* **Frontend:** Bootstrap 5 (para responsividade e interface limpa).
* **Ícones:** Bootstrap Icons.
* **Versionamento:** Git & GitHub.
* **Ambiente:** XAMPP (Apache/MySQL/PHP).

## 📋 Pré-requisitos

Para rodar o projeto localmente, você precisará de:

1.  [PHP](https://www.php.net/) (recomendado 8.0+)
2.  [MySQL/MariaDB](https://www.mysql.com/) (geralmente via XAMPP ou WAMP)
3.  [Git](https://git-scm.com/) instalado no seu computador.

## 🔧 Instalação e Configuração

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/Mariaclara2424/Gestiq.git](https://github.com/Mariaclara2424/Gestiq.git)
    ```

2.  **Mova para a pasta do XAMPP:**
    Coloque a pasta dentro de `C:/xampp/htdocs/gestiq`.

3.  **Configuração de Banco de Dados:**
    * Importe o arquivo SQL do sistema (se houver) no seu `phpMyAdmin`.
    * Configure as credenciais de acesso ao banco nos arquivos de configuração do seu sistema (config/database.php ou similar).

4.  **Acesso:**
    Abra o seu navegador e acesse: `http://localhost/gestiq`
